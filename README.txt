U.E.E REBUILT — DESKTOP v2.0.0 MAJOR REBUILD

An unofficial, community-made Project Moon character and Mirror World variant builder.

DESKTOP REBUILD
- Independent desktop entry point at desktop/index.html; the website landing page is excluded.
- Completely new five-section Character Creator.
- Completely new Character Archive with search, sorting, record preview, editing, copying, deletion, backup, and restore.
- New archive storage namespace; older website and desktop characters are not automatically imported.
- Preserved Settings, 20 visual effects, accessibility and performance controls, custom background, original ambient music, interface sounds, Lore Book, Mirror Arena, Multiplayer Arena, Mirror Observatory, and the hidden Sephrus gate.

WEBSITE
- The website keeps its own browser entry point and original creator experience.
- Cloudflare Pages continues to deploy from the repository's main branch.

MAIN DESKTOP FILES
- desktop/index.html — dedicated desktop entry point.
- desktop/app.js and desktop/app.css — new desktop application shell, Character Creator, and Character Archive.
- desktop/modules/ — preserved desktop Settings and Simulator modules.
- desktop/vendor/ — preserved Multiplayer and Lore Book modules and legacy styles.
- src-tauri/ — Tauri v2 desktop application and updater configuration.

This is an unofficial fan-made project and is not affiliated with Project Moon.
