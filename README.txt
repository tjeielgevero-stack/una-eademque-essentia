U.E.E REBUILT — DESKTOP v2.0.0 MAJOR REBUILD

An unofficial, community-made Project Moon character and Mirror World variant builder.

WHAT'S NEW
- Independent desktop entry point; the website landing page is not bundled into the desktop app.
- Completely new guided Character Creator and separate Character Archive.
- Preserved Settings, effects, accessibility, Lore Book, Simulator, Multiplayer, Mirror Observatory, and hidden desktop gate.
- Better parry timing and corrected three-step multiplayer regression tests.
- Corrected the archive change record and release labels.
- Updated desktop installer links and refreshed offline cache versions.

MAIN FILES
- desktop/index.html — dedicated desktop interface.
- desktop/app.js and desktop/app.css — rebuilt desktop navigation, Creator, Archive, and visual layout.
- desktop/modules/ and desktop/vendor/ — preserved desktop modules.
- multiplayer.js — multiplayer interface.
- multiplayer/src/index.js — Cloudflare multiplayer Worker.
- multiplayer/smoke-test.mjs — multiplayer integration tests.
- service-worker.js — offline cache behavior.
- src-tauri/ — desktop app and updater configuration.

SETTINGS
Custom accent, background, ambient audio, interface sounds, visual effects, reduced motion, low-performance mode, high contrast, larger text, compact layout, question hints, delete confirmation, default archive sorting are configurable.

This is an unofficial fan-made project and is not affiliated with Project Moon.
