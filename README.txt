UNA EADEMQUE ESSENTIA — DESKTOP v1.0.1 MINOR UPDATE

An unofficial, community-made Project Moon character and Mirror World variant builder.

WHAT'S NEW
- Additional character-creation choices.
- Saved-character archive search, creation-mode filters, and sorting.
- New accessibility, performance, creator, and archive preferences.
- Better parry timing and corrected three-step multiplayer regression tests.
- Corrected the archive change record and release labels.
- Updated desktop installer links and refreshed offline cache versions.

MAIN FILES
- index.html — app interface, Settings, creation screens, archive and release notes.
- style.css — responsive styling, visual effects, accessibility and performance preferences.
- script.js — creator, dossier formatting, archive search and settings persistence.
- multiplayer.js — multiplayer interface.
- multiplayer/src/index.js — Cloudflare multiplayer Worker.
- multiplayer/smoke-test.mjs — multiplayer integration tests.
- service-worker.js — offline cache behavior.
- src-tauri/ — desktop app and updater configuration.

SETTINGS
Custom accent, background, ambient audio, interface sounds, visual effects, reduced motion, low-performance mode, high contrast, larger text, compact layout, question hints, delete confirmation, remembered creation mode, and archive sorting are configurable.

This is an unofficial fan-made project and is not affiliated with Project Moon.
