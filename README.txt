UNA EADEMQUE ESSENTIA — v1.0.0 SUPER-MASSIVE RELEASE

An unofficial, community-made Project Moon character and Mirror World variant builder.

WHAT'S NEW
- Seven searchable fictional weapon styles, including thrown/returning and summoned/construct.
- A much larger fantasy weapon catalogue and additional character choices.
- Saved-character archive search, creation-mode filters, and sorting.
- New accessibility, performance, creator, and archive preferences.
- Better parry timing and corrected three-step multiplayer regression tests.
- Updated desktop installer links and offline cache versions.

MAIN FILES
- index.html — app interface, Settings, creation screens, archive and release notes.
- style.css — responsive styling, visual effects, accessibility and performance preferences.
- script.js — creator, catalogues, weapon search, dossier formatting, archive search and settings persistence.
- multiplayer.js — multiplayer interface.
- multiplayer/src/index.js — Cloudflare multiplayer Worker.
- multiplayer/smoke-test.mjs — multiplayer integration tests.
- service-worker.js — offline cache behavior.
- src-tauri/ — desktop app and updater configuration.

WEAPON CATALOGUE
Melee, Ranged, Unarmed, Hybrid / Transforming, Focus / Conduit, Thrown / Returning, and Summoned / Construct are the seven supported fighting styles. New entries are fictional design concepts for character creation.

SETTINGS
Custom accent, background, ambient audio, interface sounds, visual effects, reduced motion, low-performance mode, high contrast, larger text, compact layout, question hints, delete confirmation, remembered creation mode, default weapon style, and archive sorting are configurable.

This is an unofficial fan-made project and is not affiliated with Project Moon.
